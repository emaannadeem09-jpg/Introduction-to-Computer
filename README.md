## Introduction to Computers
A computer is an electronic device that manipulates information or data. It has the ability to store, retrieve, and process data. Computers take data as input, process it through a CPU, and produce meaningful information as output.

## Types of Computers
Computers are categorized based on their speed, capacity, and size:

1. **Supercomputers:** The most powerful computers used for complex calculations (weather forecasting, scientific research).
2. **Mainframe Computers:** Large systems used by big organizations for bulk data processing (banks, airlines).
3. **Minicomputers (Midrange):** Medium-sized servers used by small businesses.
4. **Microcomputers (Personal Computers):** Desktops, laptops, tablets, and smartphones used by individuals.
